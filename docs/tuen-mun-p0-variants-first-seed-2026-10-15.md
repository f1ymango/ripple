## Reproduction

From this branch with SUMO 1.27.1 and the repo's Python environment:

```powershell
..\.venv\Scripts\python.exe scripts\tuen_mun\p0_variants_oct15.py
..\.venv\Scripts\python.exe -m src.evaluator.run --plans data/generated-plans/IN-26-02615-lead-capacity-oct15 --plan-set lead-capacity-p0-variants --plan P0 --scenario sim/scenarios/tuen-mun/evaluator_IN-26-02615_p0-middle-open-s2029.json --compliance 0.5 --clearance 59 --results-dir results/tuen-mun-p0-variants-oct15

..\.venv\Scripts\python.exe scripts\tuen_mun\verify_p0_variants_oct15.py
```

Replace `p0-middle-open-s2029` with `p0-td-one-lane-s2029` or `p0-no-residual-s2029` for the other runs. The `.venv` command is relative to this isolated worktree; use the equivalent installed Python when running in another checkout.
The verifier checks all three result sidecars against both worktree and staged Git bytes, including the canonical JSON result hash and exact scenario and route hashes. It passed before publication.
